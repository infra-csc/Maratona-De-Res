# Registro de decisões

Cada arquivo desta pasta registra **uma** decisão técnica, regra de negócio
não óbvia ou incidente passado: o que foi decidido, por quê e como aplicar.
O índice com um resumo de cada arquivo está em [MEMORY.md](MEMORY.md).

A maioria foi escrita durante o desenvolvimento no Replit, em inglês, e
algumas citam caminhos ou comandos daquela época. Antes de seguir uma
instrução daqui, confira se o arquivo ou função citada ainda existe.

Ao registrar uma decisão nova:

1. Crie `nome-curto.md` com o cabeçalho `name` / `description` e o texto
   (decisão, **Por quê**, **Como aplicar**), de preferência em português.
2. Acrescente uma linha em `MEMORY.md` com o link e um resumo de uma linha.
3. Nunca coloque senhas, tokens, IPs de servidor ou dados pessoais.
